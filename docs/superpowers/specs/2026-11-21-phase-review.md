# 논스톱 3단계 제작과 2회 검수

S00–G2 PRE: 대본(의도), 콘티(연출 지시), 보드(화면)를 쌍별로 대조한다. 러프·프리비즈는 설계용이며 촬영용 참조를 확보했다는 뜻이 아니다. S08 PROD: 실제 참조·테이크·원본 음성을 확보하고 제출 직전 요청을 별도로 검사한다. S09–S11 POST: 채택 구간 조립, 실측 음성 정렬, 색·믹스·자막·출력본 재생 검사. S12는 운영 피드백이다.

각 컷의 must-show/must-hide, 정보 공개 시점, 행동 원인→반응, 페르소나와 연기, 에셋 가시성, 대사·톤·속도, 소리 출처와 동기를 검토한다. 서로 독립인 관점은 병렬 평가 가능하나 수정 지시는 단일 소유자가 사용자 제약 > 서사 기능 > 취향 순으로 통합한다. 영상 요청은 실제 prompt/params/refs만으로 먼저 예상 시작·행동·끝을 기술한 뒤 승인 의도와 비교한다. 예측은 실측이 아니다.

작품당 pre와 prompt 묶음 각각 최대 두 회. 입력 준비/호스트 응답 대기는 횟수에 미포함. 첫 검수는 전수, 문제 없으면 종료. 문제가 있으면 한 번에 수정하고 두 번째는 영향 범위만 확인한다. 재시작·파일 수정으로 회차 초기화 금지. 남은 연출 위험은 마지막 검사본에 기록하고 진행한다. 권리·권한·지원 규격은 예외 없는 실행 전제다. 검수는 재생성 허가가 아니다. 생성 후 테이크 채택은 필요한 편집 구간의 유무로 판정한다.
