- [x] 납품: 사용자가 검토한 영상 해시를 `cineforge motion --deliver <sha256>`로 명시한 경우에만 사본과 납품 JSON. 변경된 계획·프리뷰는 납품 거부. 테스트 프로젝트에서만 권한 경로 검증, 실제 납품은 사용자 확인 전 보류.
- [x] UI/타이포 테스트, 기존 실제 호스트 기획의 복사본 로컬 프리뷰, 기술 검사/대표 프레임 기록. 커밋·푸시는 밖.
