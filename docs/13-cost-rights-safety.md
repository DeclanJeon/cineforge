# 13. 비용·권리·안전

## 1. 비용(L4)

- CineForge 자체는 유료 이미지·영상 생성 API를 부르지 않는다. 판단(Jev)과 문장 생성(OpenRouter, 기본 `openai/gpt-6.1-terra`)은 사용자가 `OPENROUTER_API_KEY`를 설정했을 때만 쓴다. 문장 생성만 끄려면 `CINEFORGE_GEN_MODEL=off`.
- G2의 `cost_plan`: 컷마다 난이도 = 제작 방식 난이도 + 인물 수 + 카메라 움직임(2) + 상태 변화(1) + 5초 초과(1). 상위 20% 컷만 `high` 티어, 나머지 `standard`.
- 단가는 `UNVERIFIED` — 실행 직전 공급자 가격을 실제 조회한다(스킬의 실행 게이트).
- 재생성 정책: 검수 실패 컷과 영향 분석으로 나온 의존 대상만.
- 생성 권한은 `grant execution --spend-ceiling`으로 한도와 함께 기록. 한도는 인계 패킷에 들어가고 실행 스킬이 지킨다.

## 2. 권리(L5)

- 레퍼런스·드라마 각색: 구조·리듬·장르 문법만 참고. 원본 영상·음악·대사 재사용 금지, 원작 캐릭터 복제 금지. 출처를 기록한다.
- 실존 인물: 초상·음성 동의가 없으면 RS01 error.
- 음원: 생성 또는 라이선스가 확인된 것만. 미확인은 RS02 error.

## 3. 안전·표기

- AI 생성 콘텐츠는 게시 시 플랫폼의 AI 표시 기능·해시태그로 공개. 영상 안에 'Made with AI' 코너 라벨은 넣지 않는다(프롬프트 네거티브에도 포함).
- 한서윤(AI 페르소나) 콘텐츠: AI임을 숨기지 않음, 영상은 대사 없음(요청에 이름이 나오면 자동 제약).
- 비밀: 키는 환경변수만. 파일·로그·명령 인자 금지. `provider_log.json`에는 공급자 이름·상태·오류 요약만.
- 외부 행동(게시·전송·결제·OAuth·푸시)은 CineForge 범위 밖이며 사용자 승인 없이는 스킬도 하지 않는다.
