# 01. 요구사항 명세(SRS)

## 1. 목적과 범위

사용자가 만들고 싶은 영상을 자유롭게 말하면, 시스템이 필요한 판단 요소를 분석하고, **모든 선택을 처음 한 번에** 받은 뒤, 콘셉트 조합·적합성 검사·평가 → 기획안 → 검수 → 에셋 준비 → (승인 시) 생성 → 편집 → 검수 → 출력까지 끊김 없이 진행한다. 진행 중에는 작업률·진행률·검수 상태를 보여준다.

범위 안: 대화형 CLI, 콘셉트 엔진, 기획안 생성(호스트 AI/생성 모델), SSOT·에셋·프롬프트·사운드 큐 시트 작성, 자동 검수, 스킬 인계 패킷, 진행 표시.
범위 밖(MVP): 유료 생성 API 직접 호출, 영상 편집 실행, 게시. 이들은 `contents-production-skills`의 해당 스킬이 사용자 승인 아래 수행한다.

## 2. 이해관계자

- 제작자(사용자): 요구사항과 선택을 주고, 게이트에서 승인한다.
- 호스트 AI 에이전트: CLI가 맡긴 판단·문장 생성을 수행하고, 외부 단계를 스킬로 실행한다.
- 스킬 패키지: 단계별 전문 작업(시놉시스, 캐릭터, 콘티, 카메라, 생성, 편집, 이력).

## 5. 사용자 스토리와 인수 기준

1. **한 번에 고르고 끝까지** — "60초 코미디 숏드라마, 시네마틱 실사, 결말 선공개"라고 말하면, 감지된 항목은 묻지 않고 남은 항목만 묻는다. 인수: 감지 값의 출처가 `request`로 기록되고, 질문 목록에 없다.
2. **맡기기** — "나머지는 알아서"(!) 입력 시 남은 필수 축이 추천으로 채워지고 출처는 `ai`. 인수: `selection.sources`.
3. **충돌 경고** — 스틱맨 제작 + 포토리얼 질감은 진행이 막히고 해결책이 표시된다. override로 통과 가능. 인수: C001 blocking, override 후 통과.
4. **시대 연출** — 1998년 배경 선택 시 금지 소품(스마트폰 등)이 연출 규칙에 들어가고, 프롬프트에 나오면 G2가 오류를 낸다. 인수: CQ10.
5. **기획안 형식** — 기획안이 7섹션(시놉시스, 후킹, 타임라인, 씬/컷 표, 캐릭터, 촬영·편집·사운드, 확인 사항)으로 나오고 컷 합계 = 러닝타임. 인수: P01·P02 pass.
6. **논스톱** — `--nonstop`이면 G1·G2가 자동 통과로 기록되고 생성 단계 앞에서 실행 권한을 요구하며 멈춘다. 인수: S08 `blocked`.
7. **생성 인계** — 권한 부여 후 S08은 `waiting_external`, 증거 파일과 함께 complete 하면 done. 증거 없으면 거부.
8. **진행 표시** — `status`가 진행률·작업률 막대, 단계별 상태·검수·담당 스킬을 보여준다.
9. **호스트 AI** — 키가 없고 host 모드면 `agent_io/requests`에 질문이 생기고, 응답을 쓰면 `run`으로 이어진다.
10. **연속성** — 이전 컷 끝에서 오른손에 든 펜이 다음 컷 시작에서 왼손이면 G2가 CQ02 오류를 낸다.

## 6. 제약·가정

- 사용자 규칙: 외부 게시·전송·결제·OAuth·GitHub 푸시는 사용자 승인 없이는 하지 않는다. 한서윤이 AI임을 숨기지 않는다. 한서윤 영상은 대사 없음. 영상에 'Made with AI' 코너 라벨을 넣지 않는다. 드라마 각색은 원본 영상·음악·대사를 재사용하지 않고 원작 캐릭터를 복제하지 않는다.
- OpenRouter 경유 Jev는 Decisions API(`POST /api/alpha/decisions`)로 2026-11-19 실호출 확인(10 문서, ADR-009).
