# ADR-006 스킬 저장소에 R33 + concept-intake-design 추가

- 상황: 총괄 스킬에는 업프런트 인테이크를 맡을 담당이 없었다(R02는 시놉시스 하나, R05는 여러 텍스트 산출물).
- 결정: `concept-intake-design`(1.0)과 route R33(text_only)을 추가하고, creative-production에 Step 0을 넣는다. 구분 행 R02/R33, R05/R33과 라우팅 사례 I01·I02·B26.
- 결과: 도달성 테스트·라우팅 린트 통과. 실제 라우팅 정확도(codex 하네스)는 아직 측정하지 않았다.
