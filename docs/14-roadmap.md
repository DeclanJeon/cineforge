# 14. 로드맵(6단계)

> 단계 이름과 결과물은 사용자 원문 로드맵(1~6단계)을 그대로 따른다. 엔진·계층 열은 이 프로젝트의 매핑이다.

| 단계 | 우선 구현할 기능(원문) | 결과물(원문) | 엔진·계층 | 상태 |
|---|---|---|---|---|
| 1단계 | 콘셉트 라이브러리 + 조합·평가 | 작품 콘셉트와 기획안 | E01(일부)·E02·E03·E04, L1 | **구현(v0.1.0)**: CLI new/select/run/status, taxonomy·rules, plan.json/md, G1 |
| 2단계 | 스토리·캐릭터·세계관 + SSOT | 시놉시스, 대본, 캐릭터 바이블 | E05–E08, L2 | **구현(규칙 기반)**: 8종 SSOT·버전·잠금·영향 분석, 캐릭터 바이블 템플릿. 스킬로 품질 보강 |
| 3단계 | 연출·스토리보드·타이밍 | 씬·컷·키프레임 제작 명세 | E09–E11 | **구현(규칙 기반)**: 씬/컷 상태, 시작/끝 프레임, 연출 규칙 팩 |
| 4단계 | 프롬프트·모델 라우팅·생성 | 이미지·영상·음성 에셋 | E12–E14, L4 | **프롬프트·큐시트·인계 구현**, 실제 생성은 스킬 담당(사용자 승인 후) |
| 5단계 | 편집·연속성 검수 | 완성 영상 | E15·E16, L3 | **연속성 규칙 CQ01–CQ11·G2 구현**, 편집 실행·자동 품질 평가는 설계 |
| 6단계 | 성과 분석·자동 개선 | 차기 콘텐츠 기획 개선 | E01·E04, L6 | 설계 |
