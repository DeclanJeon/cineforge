## 요약
터미널에서 `cineforge`를 실행하면 설치된 AI 에이전트를 선택할 수 있습니다. Pi는 기존 설정과 사용 가능한 프로바이더를 그대로 사용합니다.

## 새 기능
- Pi, Codex, Claude Code, agy(Antigravity CLI) 중 설치된 에이전트를 열 수 있습니다. Pi는 시작 모델을 강제하지 않으며, 세션 안에서 `/model`로 모델을 바꿀 수 있습니다.
- 새 프로젝트에서 영상·이미지·음성·음악·효과음·아바타 제작 서비스를 직접 선택할 수 있습니다. `cineforge services list`로 목록을 보고, `cineforge services setup`으로 지원되는 MCP의 등록 방법을 미리 확인할 수 있습니다.

## 수정
- 화면에 나오지 않는 내레이션과 출연진이 없는 컷을 처리하고, 제작 전 검사와 음성 서비스 연결을 개선했습니다.

## 호환성
- 스킬팩 업데이트는 이전과 동일하게 `cineforge skills update`로 직접 실행합니다.
- 에이전트 CLI 설치와 로그인은 각 에이전트에서 관리합니다. 서비스 선택은 생성, 결제 또는 게시를 승인하지 않으며, 등록된 모든 서비스가 자동 생성에 연결되는 것은 아닙니다.

## Summary
Run `cineforge` in a terminal to choose an installed AI agent. Pi uses its existing settings and available providers without narrowing model selection.

## New
- Launch Pi, Codex, Claude Code, or agy (Antigravity CLI) when installed. Pi keeps its usual startup model and lets you switch models with `/model`.
- Choose video, image, voice, music, sound effect, and avatar services for new projects. Use `cineforge services list` to browse them and `cineforge services setup` to preview supported MCP registration.

## Fixed
- Improved handling of off-screen narration and cuts with no cast, along with production preflight and voice routing.

## Compatibility
- Skill pack updates remain opt-in via `cineforge skills update`.
- Each agent manages its own CLI installation and sign-in. Choosing a service does not authorize generation, spending, or publishing, and not every listed service has an automated generation adapter.
