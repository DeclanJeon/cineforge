## 요약
요청의 완료 조건을 목표로 저장하고, 그 범위 안에서만 진행하는 선택형 목표 기반 실행을 추가했습니다.

## 새 기능
- `cineforge new ... --goal auto`: "스토리보드만" 또는 "최종 MP4"처럼 요청이 정한 지점에서 멈춥니다.
- `cineforge goal show`(읽기 전용 평가)와 `cineforge goal drive --json`(허용 범위 안에서 다음 행동 수행).
- 스토리보드 목표는 컷 고유성·카메라 연결·길이(±1프레임)·화면비를 검사하고, 생성 호출을 하지 않습니다.
- MP4 목표는 렌더·기술 QA·게이트·해당 렌더 해시에 대한 사용자 승인·납품본 해시 일치까지 확인합니다.

## 호환성
- `--goal`을 쓰지 않은 프로젝트는 이전과 같습니다.

## Summary
Optional goal-driven execution: the request's completion condition is stored as a goal and the run stops there.

## New
- `cineforge new ... --goal auto` stops at the point the request names, such as a storyboard only or a final MP4.
- `cineforge goal show` (read-only evaluation) and `cineforge goal drive --json` (next permitted action).
- Storyboard goals check cut uniqueness, camera continuity, length (±1 frame) and aspect ratio with zero generation calls.
- MP4 goals check render, technical QA, gates, user approval of that render hash and the delivered file hash.

## Compatibility
- Projects without `--goal` behave as before.
