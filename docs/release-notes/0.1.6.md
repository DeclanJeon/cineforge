## 요약
스킬팩을 CineForge 명령으로 확인·설치·전환할 수 있습니다. 업데이트는 직접 실행할 때만 일어나고, 진행 중인 프로젝트는 처음 고정한 팩을 계속 씁니다.

## 새 기능
- `cineforge skills update --check`: 최신 스킬팩 릴리스와 변경 내용을 확인합니다(아무것도 쓰지 않음).
- `cineforge skills update --yes`: 내려받은 아카이브를 SHA-256으로 검증한 뒤 버전별 폴더에 설치하고, 새 프로젝트의 기본 팩으로 지정합니다.
- `cineforge skills list`, `cineforge skills use <버전>`, `cineforge skills use --default`로 설치된 버전을 보고 전환합니다.

## 개선
- 활성 버전을 바꿔도 기존 프로젝트는 저장된 버전 폴더에서 고정된 팩을 찾습니다.
- `CINEFORGE_SKILL_PACK`이 설정돼 있으면 활성 버전보다 우선한다는 경고를 보여 줍니다.

## 호환성
- 설치 위치: `~/.local/share/cineforge/skill-packs/`(XDG_DATA_HOME 우선). 이전 버전 폴더는 지우지 않습니다.
- Contents Production Skills 2.64 이상의 릴리스 아카이브를 사용합니다.

## Summary
CineForge can now check, install and switch skill packs. Updates happen only when you run them, and projects in progress keep the pack they were pinned to.

## New
- `cineforge skills update --check` shows the latest skill pack release and what changed, without writing anything.
- `cineforge skills update --yes` verifies the archive's SHA-256, installs it into a versioned folder and makes it the default for new projects.
- `cineforge skills list`, `cineforge skills use <version>` and `cineforge skills use --default` show and switch installed versions.

## Improved
- After switching the active version, existing projects still find their pinned pack among the stored versions.
- A warning appears when `CINEFORGE_SKILL_PACK` overrides the active version.

## Compatibility
- Install location: `~/.local/share/cineforge/skill-packs/` (XDG_DATA_HOME first). Older version folders are never deleted.
- Uses release archives of Contents Production Skills 2.64 or later.
