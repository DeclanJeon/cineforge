## 요약
CineForge가 버전이 있는 제작 스킬팩(v1)을 읽습니다. 프로젝트는 생성 시 사용한 스킬팩을 고정하므로, 새 스킬팩이 나와도 진행 중인 프로젝트는 그대로 이어집니다.

## 새 기능
- 설치된 v1 스킬팩 인식과 `cineforge skills` 진단(버전·파일 해시).
- 프로젝트별 스킬팩 고정(pin): 새 프로젝트만 다른 호환 팩을 채택합니다.

## 호환성
- [Contents Production Skills 2.64](https://github.com/DeclanJeon/contents-production-skills/releases/tag/v2.64) 이상을 설치하고 `CINEFORGE_SKILL_PACK`을 압축을 푼 팩 폴더로 지정하세요.
- 진행 중인 프로젝트를 위해 이전 버전 팩 폴더를 지우지 마세요. 팩 고정 이전에 만든 프로젝트는 기존 방식으로 계속됩니다.

## Summary
CineForge reads versioned v1 production skill packs. Each project pins the pack it was created with, so a new pack never changes a project in progress.

## New
- Installed v1 skill-pack discovery and `cineforge skills` diagnostics (version and file hashes).
- Per-project pack pins: only new projects adopt a different compatible pack.

## Compatibility
- Install [Contents Production Skills 2.64](https://github.com/DeclanJeon/contents-production-skills/releases/tag/v2.64) or later and point `CINEFORGE_SKILL_PACK` at the extracted pack.
- Keep older pack directories for projects in progress. Projects created before pinning continue in legacy mode.
