## 요약
캐릭터 대사를 기본적으로 영상 모델이 같은 요청 안에서 음성과 함께 생성합니다. 별도 음성(TTS)은 요청할 때만 계획됩니다.

## 개선
- 대사는 영상 요청의 오디오 구획(화자·대사·고정 음성 정체성)에 들어가며, 별도 `dialogue` 작업을 만들지 않습니다.
- 모델의 네이티브 오디오 지원 여부는 실행 직전에 확인하도록 `UNVERIFIED`로 기록합니다.
- 별도 음성이 필요하면 `cineforge new ... --external-voice`를 씁니다. 무대사(`--no-speech`)는 그대로 무음입니다.

## 호환성
- 스킬팩 지원(0.1.4)을 그대로 포함합니다.

## Summary
Character dialogue is now generated natively by the video model in the same request. A separate voice (TTS) is planned only on request.

## Improved
- Dialogue goes into the video request's audio section (speaker, line, fixed voice identity); no separate `dialogue` job is created.
- Native audio support is recorded as `UNVERIFIED` and checked right before execution.
- Use `cineforge new ... --external-voice` for a separate voice. `--no-speech` stays silent.

## Compatibility
- Includes skill-pack support from 0.1.4.
