## 요약
코드 모션 컷을 제작 흐름에 연결하고, 렌더된 MP4를 검증한 뒤 재생 확인을 거쳐야 납품되도록 했습니다.

## 새 기능
- 코드 모션 컷(`code-motion`) 범위 지정: HTML 모션 렌더 결과를 컷 단위로 받습니다(생성 비용 없음).
- MP4 영수증 검증: 파일 SHA-256을 고정하고 바뀐 파일은 거부합니다.
- 컷별 테이크 선택(`select-take`)과 재생 검수 후에만 진행되는 납품.

## 호환성
- contents-production-skills의 코드 모션 도구가 필요합니다.

## Summary
Code-motion cuts join the production flow, and rendered MP4s must pass receipt checks and playback review before delivery.

## New
- `code-motion` cut scoping for HTML motion renders (no generation cost).
- MP4 receipt validation that pins SHA-256 and rejects a changed file.
- Per-cut take selection (`select-take`) and playback-gated delivery.

## Compatibility
- Requires the contents-production-skills code-motion tooling.
