## 요약
첫 공개 릴리스입니다. 요청 한 줄에서 기획안·스토리보드·에셋 패키지·검수 게이트까지 이어지는 대화형 제작 오케스트레이터와, 새 프로젝트의 안정적인 프로젝트 ID를 제공합니다.

## 새 기능
- 요청에서 감지한 항목은 다시 묻지 않는 한 번의 선택(`?` 추천, `!` 나머지 맡기기, `--non-interactive`).
- 18개 축·377개 항목의 콘셉트 라이브러리(`cineforge taxonomy`)와 적합성 규칙·6개 기준 평가.
- 7섹션 제작 기획안, 씬·컷·타임라인, SSOT 8종과 해시 기반 잠금·변경 영향 분석.
- 등장인물·배경·컷별 시작/끝 프레임·생성 프롬프트·사운드 큐가 담긴 에셋 패키지.
- G1 기획안, G2 연속성·권리, G3 최종 검수 게이트와 `cineforge route`·실행 계획 승인·`verify --attest`.
- 로컬 모션 그래픽 렌더(`cineforge motion`), 컷 수정 인계(`--cut-revision`).
- 새 프로젝트는 요청문 대신 짧은 ASCII 프로젝트 ID를 씁니다. 대화형에서는 ID를 묻고, 비대화형에서는 `--project-id`를 넘깁니다.

## 호환성
- 기존 프로젝트 폴더와 작품 제목은 바뀌지 않습니다.

## Summary
First public release: a conversational production orchestrator that turns one request into a plan, storyboard, asset package and review gates, with stable project IDs for new projects.

## New
- One-pass selection that never re-asks what the request already says (`?` recommend, `!` delegate the rest, `--non-interactive`).
- A concept library of 18 axes and 377 entries (`cineforge taxonomy`) with compatibility rules and six-criterion scoring.
- A seven-section production plan, scenes/cuts/timeline, eight SSOT files with hash-based locks and impact analysis.
- Asset packages: characters, locations, per-cut start/end frames, generation prompts and sound cues.
- Review gates G1/G2/G3 plus `cineforge route`, execution-plan approval and `verify --attest`.
- Local motion-graphics rendering (`cineforge motion`) and cut-revision handoffs (`--cut-revision`).
- New projects use a short ASCII project ID instead of a prefix of the request (prompted interactively, `--project-id` otherwise).

## Compatibility
- Existing project folders and work titles are unchanged.
